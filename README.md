# Kronos Technology - NeuroHeadset

Sitio web moderno y responsivo para el lanzamiento de un producto tecnológico ficticio ("NeuroHeadset"), desarrollado con HTML, CSS y JavaScript.

## Características del Proyecto
* **Estructura Multipágina**: Navegación fluida entre las secciones de Inicio (`index.html`), Detalle de Producto (`producto.html`) y Formulario de Contacto (`contacto.html`).
* **Se adapta a celulares**: Si achicás la pantalla o entrás desde el teléfono, el diseño se acomoda solo y aparece un botón de tres rayitas (☰) para abrir y cerrar el menú.
* **Componentes Interactivos**: Implementación de un modal dinámico de compra con cálculo de precios en tiempo real y validación/simulación de envío en los formularios.
* **Formularios controlados con JS**: Programé el código para que cuando mandes un mensaje de contacto o simules la compra, los datos se limpien solos y aparezca un aviso en pantalla.

## 🛠️ Tecnologías utilizadas
* **HTML**
* **CSS**
* **JavaScript**
